# AVA 智慧师范实训平台 (AVA Smart Normal Training Platform)

![AVA Platform](https://images.unsplash.com/photo-1509062522246-3755977927d7?auto=format&fit=crop&q=80&w=1200)

## 📖 项目简介

**AVA 智慧师范实训平台** 是一款专为师范院校设计的高保真、数字化实训管理生态系统。该平台利用 AI 技术对师范生教学技能进行全方位采集与深度分析，实现实训流程的标准化、数据化与智能化。

通过全息数据驱动，平台为师生提供沉浸式的实训体验，涵盖了从场地预约、作业管理到 AI 技能诊断及成长画像的全生命周期管理。

## ✨ 核心特性

- 🚀 **全息数据中台**：集成异构系统数据，通过全息校园节点分布图实时监控实训资源动态。
- 🤖 **AI 教学技能分析**：利用多模态 AI 算法，对微格试讲进行深度剖析（语速、板书、仪态、互动等），并生成专业诊断报告。
- 📊 **学生成长画像**：多维度量化师范生能力发展趋势，提供精准的教学技能达标分析。
- 🏢 **场地与设备运维**：高效的场室预约系统与实时监控的设备健康管理中心。
- 🛡️ **角色定制化视图**：针对师范生、指导教师及校领导提供定制化的功能入口与数据看板。

## 🚀 快速开始

### 环境要求

- [Node.js](https://nodejs.org/) (建议 v18+)
- [npm](https://www.npmjs.com/) 或 [yarn](https://yarnpkg.com/)

### 安装与运行

1. **克隆仓库**
   ```bash
   git clone https://github.com/lzytttttt/nudemo1.git
   cd nudemo1
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动开发服务器**
   ```bash
   npm run dev
   ```

4. **构建项目**
   ```bash
   npm run build
   ```

## 📸 界面预览

- **角色导航/登录**：科技感十足的入场动效，多身份快捷切换。
- **智慧实训看板**：实时汇总全校实训态势与核心指标。
- **AI 技能诊断**：交互式雷达图与视频智能理答辅助。
